## 运动学结构

6 个旋转关节串联构型。从 URDF 提取的运动学链：

```
base_link (底座, 1.94kg)
  │
  ├─ J1 (底座旋转, axis=Z) ─── link1 (0.62kg)
  │     origin: (0, 0, 0)
  │
  ├─ J2 (肩关节, axis=-Z) ─── link2 (0.57kg)
  │     origin: (0.055, -0.02, 0.166)  ← link1 高 166mm
  │     连杆长: 200mm (J2→J3)
  │
  ├─ J3 (肘关节, axis=-Z) ─── link3 (0.55kg)
  │     origin: (0, 0.2, 0)  ← link2→3 长 200mm
  │
  ├─ J4 (手腕旋转1, axis=-Z) ─── link4 (0.40kg)
  │     origin: (0, -0.056, -0.02)
  │
  ├─ J5 (手腕俯仰, axis=-Z) ─── link5 (0.15kg)
  │     origin: (0, 0, -0.192)  ← link4→5 长 192mm
  │
  └─ J6 (末端旋转, axis=Z) ─── link6 (末端法兰, 0.02kg)
        origin: (-0.055, 0, 0)  ← link5→6 偏移 55mm
```

总质量约 4.25kg。末端法兰到 J5 距离 55mm，J5 到 J4 距离 192mm。

## 关节耦合规律（Agent 必须理解）

末端姿态由多个关节共同决定，不是独立的 6 个自由度：

- **J1 (底座)**: 控制左右方向旋转
- **J2 (肩) + J3 (肘)**: 共同决定末端高度和前后距离。J2 是大臂，J3 是小臂
- **J5 (手腕俯仰)**: 决定末端工具（摄像头/夹爪）的朝向
- **J4/J6 (手腕旋转)**: 末端绕轴微调

### 朝下看的补偿关系

**J2/J3 增大（抬臂）→ J5 必须减小（手腕下压）才能保持末端朝下**，反之亦然。

原因: J2/J3 抬升改变了末端的空间位置，J5 需要反向补偿来维持朝向角度。

### 已验证的朝下看关节范围

- J1 ≈ 180° (正前方)
- J2 ∈ [120, 121]°
- J3 ∈ [59, 103]°
- J5 ∈ [145, 197]°

## move_robot_xyz 行为（重要陷阱）

`move_robot_xyz(x, y, z, speed_ratio, rotation)` 的 rotation **默认值是 (180, 0, 90)**（Home位欧拉角）。

只传 x/y/z 不传 rotation → 末端姿态被重置为默认值 → **破坏当前摄像头朝向**。

### 正确做法

| 场景 | 方法 |
|------|------|
| 保持姿态只改位置 | 先 get_robot_status 获取当前 rotation，原样传给 move_robot_xyz |
| 改高度保持朝下 | 用 move_robot_joints 调 J2/J3，按耦合规律补偿 J5 |
| 精确控制 | 优先用 move_robot_joints（关节空间），少用 move_robot_xyz（有 IK 奇异点风险）|
