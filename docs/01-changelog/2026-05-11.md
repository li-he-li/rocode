# 2026-05-11 — 日志系统重构 + CLI 补全

## 改动 1: 日志系统重构
- 用户要求：开发日志从简洁的 `log/` 升级为更完整的 `docs/` 分类目录，方便 AI clean 后快速恢复上下文
- 改动内容：
  - 新建 `docs/` 目录，6 个分类子目录
  - 将 `log/` 中 6 个日志文件（04-28 ~ 05-07）按内容拆分到 01~05 分类，共 20 个文件
  - 每个文件添加 YAML frontmatter（tags / date / summary / status）
  - 编写 `docs/index.md`：当前状态摘要 + 模块地图 + 标签索引 + 时间线
  - 创建 `docs/06-ai-assets/model-version.log`：模型版本/参数/环境记录
  - 更新 `CLAUDE.md` 第 5 节日志规范 + 目录结构说明
- 设计原则：
  - frontmatter 供 AI 快速扫描（tag → 定位相关日志）
  - index.md 为 AI 恢复上下文第一入口（一屏内了解项目全貌）
  - 分类维度：changelog（功能）/ debug（Bug）/ tests（测试）/ reviews（审查）/ design（设计决策）
  - 原 `log/` 保留为纯运行时输出目录

## 改动 2: / 命令 Tab 补全功能

- 用户要求：输入 `/` 后显示命令预览列表，支持搜索过滤和 Tab 补全，类似 Claude Code 主流 agent 体验
- 改动内容：
  - `slash.py`:
    - `SlashDispatcher.__init__` 新增 `_descriptions` 字典，内置命令表改为 `(cmd, desc, handler)` 三元组
    - `register_skill` 同步写入 `_descriptions`
    - 新增 `get_command_list()` 方法返回 `[(cmd, desc), ...]`
    - 新增 `SlashCompleter` 类实现 `prompt_toolkit.completion.Completer` 接口
  - `app.py`:
    - 导入 `SlashCompleter`
    - `PromptSession` 设置 `completer=SlashCompleter(self.slash)` 和 `complete_while_typing=True`
- 行为：
  - 输入 `/` → 自动弹出 10 个内置命令 + N 个技能命令的下拉菜单（含描述）
  - 输入 `/h` → 过滤仅显示匹配命令（如 `/help`）
  - 补全菜单打开时 Enter → 填入输入框（不发送），可继续追加需求
  - Tab 键 → 补全当前选中命令
  - 非 `/` 输入 → 无补全弹出，不影响正常对话
- 验证：26/27 CLI 测试通过（1 预存失败无关），新增 13 个测试全部通过
- 审查：Gatekeeper 一轮 FAIL（P1#1 VoiceState 误判 + P1#2 缺测试）→ 补测试 → 二轮 PASS ✅

## 改动 3: 信息类命令追加追问 → LLM

- 用户要求：`/{skill}` + 用户要求回车后直接发给 LLM；补全菜单 Enter 填入输入框不发送
- 改动内容：
  - `app.py`:
    - 新增 `has_completions` filter，绑定 Enter 键在补全菜单打开时仅接受补全不提交
    - `_handle_slash` 处理新增 `action="chat"`
  - `slash.py`:
    - 新增 `_chat_if_args()` 辅助方法：无参时直接返回，有参时打包命令输出 + 追问 → `action="chat"`
    - `/help` `/status` `/tools` `/backend` 改用 `_chat_if_args`
    - Skill handler 保持不变（无参展示信息，有参转发 LLM）
  - `tests/test_cli.py`: 新增 7 个测试覆盖 chat 转发 + 动作命令不受影响
- 验证：26/27 通过，全部 7 个新测试通过
