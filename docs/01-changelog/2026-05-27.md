## [实现内容]

按照 `.claude/plans/3-3d-locate-wise-axolotl.md` 计划完成 VLM 感知能力开发。

### Phase 1: VLM 感知后端

- `robocode/perception/__init__.py`：模块导出
- `robocode/perception/vlm_perception.py`：核心类 VlmPerception
  - `capture()`：通过 camera_bridge.py 子进程捕获一帧
  - `observe()`：VLM API 调用，返回结构化观察结果
  - `locate()`：VLM 检测 bbox → 深度反投影 → 3D 坐标
  - `_deproject_2d_to_3d()`：针孔模型深度→3D 坐标转换
- `robocode/perception/camera_bridge.py`：轻量子进程脚本，拍照保存到 /tmp
- `robocode/perception/fake_perception.py`：Sandbox 模式，返回预设 mock 结果

### Phase 2: Agent 工具注册

- `robocode/tools/perception_tools.py`：handler 工厂，返回 observe 和 locate 两个工具
- `robocode/cli/tools_setup.py`：注册 ToolEntry 和 build_handler_map
- `robocode/cli/app.py`：加载 DASHSCOPE_API_KEY，实例化 VlmPerception

### Phase 3: 强绑定钩子

- `robocode/perception/hooks.py`：HookRule + HookRegistry
  - 从 experience/vlm/vlm-hooks.md 加载规则
  - `get_pre_hooks()` / `get_post_hooks()` 获取钩子
- `robocode/agent/core.py`：_execute_tool() 方法集成 pre/post hooks
- `experience/vlm/vlm-hooks.md`：钩子规则存储

### Phase 4: 经验系统联动

- `robocode/agent/experience_filesystem.py`：CATEGORIES 加入 "perception"
- `robocode/agent/reflector.py`：REFLECTOR_SYSTEM_PROMPT 加入 VLM 观察 pattern 示例
- `experience/vlm/vlm-desktop-detection.md`：现有 bullet 加上 @observe @locate 标签

## 设计决策

- 相机在 conda episode 子进程中运行，VLM API 调用和 3D 计算在 .venv 主进程
- 深度→3D：用针孔模型 X=(u-cx)*Z/fx，像素中心点取 3x3 邻域中位数处理深度空洞
- VLM 工具自身不触发 hooks（防循环）
- Fake 模式：`--fake` 下 FakeVlmPerception 返回 mock 数据，不崩溃
