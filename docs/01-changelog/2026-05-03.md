# 2026-05-03 — 功能变更

## ESC 停止机制：纯 asyncio 重写
- 旧实现：worker 线程 + ctypes 注入 KeyboardInterrupt，不稳定
- 新实现：
  - `run()` → async，`prompt_async()` 替代同步 prompt
  - `_handle_chat()` → async，`asyncio.current_task()` 作为 agent_task
  - ESC → `task.cancel()` → `CancelledError` 原生传播到所有协程
  - 移除 threading / ctypes / signal / _cancel Event
  - `_make_display_stream()` 简化为纯显示
