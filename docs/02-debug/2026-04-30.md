# 2026-04-30 — 调试记录

## Bug 1: LLM 无法正常对话
- 根因：deepseek_provider 未传 max_tokens（默认过小）+ text_delta 用 `=` 赋值只保留最后一个字符 + CLI 未集成 AgentLoop
- 修复：max_tokens=2048、`last_text += delta`、app.py 集成 AgentLoop + DeepSeekProvider + streaming

## Bug 2: tool_result role 不被 DeepSeek 接受
- 根因：DeepSeek API 不接受自定义 `tool_result` role，必须用 OpenAI 标准 `tool` role + `tool_call_id`
- 修复：ContextMemory 新增 add_user_message/add_assistant_message/add_tool_result 方法；core.py 收集 tool_uses → 构造 assistant tool_calls 消息 → 逐条 add_tool_result

## Bug 3: SDK 连接失败误报 "机器人在线"
- 根因：EpisodeAPP 连接失败时返回 None 而非抛异常，SdkBackend 无法检测
- 修复：get_status 检查 `angles is None` → connected=False；health_check 检查 `len(angles) == 6`

## Bug 4: CLI DisplayWrapper 崩溃
- 根因：`self.inner.stream(...)` 多了一层，self.inner 本身就是 stream 方法
- 修复：`self.inner.stream(...)` → `self.inner(...)`

## Bug 5: CLI 中文流式输出乱码/频繁换行
- 根因：Rich console.print 对 Unicode 中文流式输出处理异常 + Rich status spinner 和 sys.stdout.write 并发冲突
- 修复：`display.print()` → `sys.stdout.write() + sys.stdout.flush()`；第一个 text_delta 事件时先 stop spinner 再写 stdout
