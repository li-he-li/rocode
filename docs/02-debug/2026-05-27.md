## [问题描述]

调用 `move_robot_joints` 时 LLM API 返回 400 错误：

```
Error code: 400 - {'error': {'message': "An assistant message with 'tool_calls' must be followed by tool messages responding to each 'tool_call_id', The following tool_call_ids did not have response messages: hook-pre-move_robot_joints-observe", ...}}
```

## [根因分析]

Hook 机制设计缺陷喵~

**错误流程**：
1. LLM 返回 assistant 消息（tool_calls: [move_robot_joints, id=call_123]）
2. Pre-hook 执行 observe，添加 tool message（tool_call_id=hook-pre-move_robot_joints-observe）
3. 正常工具执行，添加 tool message（tool_call_id=call_123）

**问题**：
- `hook-pre-move_robot_joints-observe` 从未在 assistant 消息的 tool_calls 中出现
- LLM API 要求 tool message 的 tool_call_id 必须与 assistant 消息中的 tool_call.id 一一对应
- 手动构造的 tool_call_id 违反了 OpenAI API 消息格式规范

## [修复方案]

将 hook 结果从 tool message 改为 user 消息注入喵~

**修改文件**：`robocode/agent/core.py`

**修改内容**：
- Pre-hooks：`self.context.add_tool_result(...)` → `self.context.add_message("user", ...)`
- Post-hooks：同上

**修改后流程**：
1. LLM 返回 assistant 消息（tool_calls: [move_robot_joints, id=call_123]）
2. Pre-hook 执行 observe，添加 user 消息（[observe 预检结果] {...}）
3. 正常工具执行，添加 tool message（tool_call_id=call_123）
