## [15:30] Reflector 架构设计决策

- 用户要求：将 LLM 反思融入现有规则分析管线
- 设计决策：
  - 两层管线：规则分析（确定性）→ LLM 反思（语义升华），互补非替代
  - Reflector 输入是规则层的结构化摘要，不是原始数据（减少噪声、降低 token 消耗）
  - LLM 产出以 bullets 形式追加到经验文件，不改变 confidence/data_points（LLM 不是 ground truth）
  - Reflector 失败不阻塞管线（try/except 跳过）
  - 去重使用 SequenceMatcher 文本相似度（阈值 0.75），不引入 FAISS

## [15:45] 索引可读性改进

- 问题：索引标题从 filename 派生（英文），小节标题无中文注释，建议与反思洞察重叠
- 决策：
  - 索引标题改为从文件 body 的 `# title` 提取（中文）
  - 工具名加中文注释映射（如 `move_robot_xyz（笛卡尔空间直线移动）`）
  - 规则建议和 LLM 反思合并为单一 `## 建议` 章节，用标签区分来源：`[RULE]` vs `[PARAM]`/`[CAUTION]`/`[PATTERN]`
