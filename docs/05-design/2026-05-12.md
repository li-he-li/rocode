# 机械臂 Agent 自进化机制 — 全流程图

## 总览

```
用户指令 ──→ 主Agent(干活) ──→ 经验管家(整理) ──→ 经验文件(知识库)
   ↑                                                    │
   └─────────────── SYSTEM_PROMPT 强制查阅 ←─────────────┘
```
