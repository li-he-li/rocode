## 三、P1 级问题（应当修复）

### P1-1：exec_tools shell 注入风险

**文件**：`robocode/tools/exec_tools.py:42-54`
**问题**：使用 `shell=True` + 字符串匹配黑名单，存在绕过可能：
- `echo $(rm -rf /)` — 命令替换未拦截
- `bash -c "rm -rf /"` — 通过 bash -c 间接执行（已修复：被 `rm -rf /` 规则捕获）
- `python3 -c "import os; os.system('rm -rf /')"` — 通过 python 间接执行（已被 `rm -rf /` 规则捕获）
- 黑名单匹配 `wget ` / `curl ` 需要尾部空格，`wget\thttp://...` 被 normalize 后也可捕获

**实际测试结果**：22 个绕过尝试中，5 个被意外捕获（黑名单比预期更宽松），0 个真实绕过成功。`echo hello > /tmp/x`（重定向）和 `echo hello >> /tmp/x`（追加）均未被 FORBIDDEN_CMDS 拦截，但被 ToolGuard._would_write_files() 在审批层捕获。

**风险评级**：中等 — 黑名单 + 审批层双重防护，但 `shell=True` 本身是隐患。

### P1-2：受保护文件列表不完整

**文件**：`robocode/orchestrator/protected_files.py`
**缺失文件**：
- `robocode/agent/core.py` — AgentLoop 主循环，控制工具执行流程
- `robocode/agent/experience_manager.py` — 经验管家，控制经验生成逻辑
- `robocode/agent/experience_reader.py` — 经验读取，注入 prompt
- `robocode/tools/motion_tools.py` — 运动工具（直接控制硬件）
- `robocode/tools/gripper_tools.py` — 夹爪工具（直接控制硬件）
- `robocode/services/analytics/db.py` — 审计数据库 schema

**风险**：Phase 2 patch 工具可以修改 agent 核心逻辑或经验系统，绕过安全约束。

### P1-3：session_summary() success_calls 计数错误

**文件**：`robocode/services/analytics/db.py:354-371`
**问题**：`session_summary()` 和 `recent_sessions_with_stats()` 中的 success 统计使用 `json_extract(result, '$.success') = 'true'`（字符串比较），但 ToolResult 序列化后 `success` 是 JSON boolean（不是字符串）。SQLite json_extract 对 boolean 返回 1/0，不是 'true'/'false'。

**实测**：1 条成功记录查询结果为 `success_calls=0`，证明查询条件不匹配。

**影响**：/audit 显示的成功率恒为 0。

### P1-4：speed_ratio 负值未校验

**文件**：`robocode/orchestrator/safety.py:83-89`
**问题**：`check_speed(-1)` 返回 `passed=True`，因为 `-1 < 0.6`。负速度在物理上无意义，可能引发后端异常。
